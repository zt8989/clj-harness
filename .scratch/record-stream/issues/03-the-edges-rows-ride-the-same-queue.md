# 03: 边的行走同一条流

**What to build:** 边写的那几批——这一轮为一次调用攒下的**请求批**、线上发出去的那些**帧**
（含运行中正文的快照）、以及**事实**——都走同一条 `push!`，并各自带上 `:producer`。
一件 item 一个号，一条队列，两个生产者。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 请求批、帧、事实的落盘行与今天逐行相同（行序、行号、字节都比对）
- [ ] 每一条 item 都带 `:producer`，且这一个字段足以说清它属于哪一批
- [ ] 记录里不再有第二个 writer：边那一侧没有绕过队列直接落行的路径
