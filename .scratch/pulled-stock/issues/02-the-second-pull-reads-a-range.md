# 02 — 二次拉：点开一处，按区间取它下面的原始那一层

**做什么**

折好的那一层（票 01）带着它自己的 `seq` 区间。用户点开它时，按这个区间**第二次拉**它下面的原始
entries，把步骤**原地**插回去。这是 ADR 0003 决策 4 的同一条路——存量是拉的——只是从「更早的历史」
扩到「每一处折起来的东西」。

本票覆盖两处，形状是同一条：

- **一轮**（会话里折好的一轮 → 它的推理 / 工具调用 / 中间消息）；
- **一个工具**（`名字 · 摘要` 那一行 → 它的参数与结果）。

**与 `.scratch/cheap-session-load` 的关系：一轮这一半 = 那份的票 04。** 工具这一半是本特征新加的
（那份只说了轮）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 一扇读门：给 `seq` 区间，答那一层的原始 entries（`reasoning`、`tool-call`、中间 assistant
      消息一样不少）；工具那一半给的是这次调用的参数与结果。
- [ ] 取回来的与**直读整份**得到的那一段**逐字节一致**——这是判据，不是「看起来一样」。
      边界逐条覆盖：区间两端、一层只有一条、一层完全没有文本。
- [ ] 只读那一段（不是读完再截）。
- [ ] 窗口的合并语义：折好的一处被展开后**原地替换**（位置不变、不新增）；展开过再折回去**不重新拉**。
- [ ] 一个还在跑的会话：正在被写的那一轮**不可展开**（它本来就没折），也不会被展开请求冻住。
- [ ] 坏的 / 不存在的区间**说出来**，不静默答一个空。
- [ ] 客户端与 `ui/test/suites/` 有对应的用例；真浏览器走查点开一处，看它确实多了一次请求。
