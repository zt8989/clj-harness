# 04: 前端校验——未重整化就禁用输入并强制走 fork

**What to build:** 客户端打开一场会话时若答案是「未重整化」：**输入框禁用**（含发送、resume、
compact 这些入口），显示一条说清「这份记录还没重整化，续跑会写出不可读的历史」的提示，
并给一个**重整化（fork）**的按钮——点它走 03 的那条门，成功后自动切到新会话。
