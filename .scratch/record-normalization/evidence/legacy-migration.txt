# 走查：旧格式记录，读得动 / 写得不得 / fork 是那把钥匙（2026-09-28）

命令（本机，只读真家；夹具与产物全在临时目录里，跑完即删）：

```
clojure -J-Dstdout.encoding=UTF-8 -M:dev -m scratch-legacy-fold
```

`step/end`），两半各印一次。下面是原样抄下来的输出：

NEW SOFAR MESSAGES ["hi"]

读数三件事：

1. `ROWS` 里每行都带 `:old-contract <旧文件的行号>`：前三条都是 1（那条 `input` 拆成了 3 行），
   后两条是 2、3 —— 所以判据那句「3 行还是旧格式」说的是**文件**的行数，不是翻译出来的 5 行；
2. `FORK-CUT {:cut 5 :at 4}`：切点是最后那条 `step/end`，切在它**之后**（`cut` 是它 +1）；
3. `NEW RAW` / `NEW ROWS` / `NEW SOFAR MESSAGES`：新记录第一条是**它自己的 header**，接着是翻译出来的
   5 行（第一行 `hi` 在——那正是 `some?`+`header?` 那个 bug 切掉的那一行），**一个 `:old-contract` 都没有**，
   折出来的消息是 `["hi"]`；原文件没在这段输出里，但用例 `a-fork-normalizes-a-record-written-in-the-old-contract`
   逐字比过它。
