# 03: agent 在运行时改自己的内核

**What to build:** 这个项目的原始命题。让 agent 用 `eval` 工具改掉**正在服务**的内核代码——改一处行为——然后在下一句话里观察到新行为，进程不重启。并且确认改坏之后能靠 02 的 replay 爬回来。

前七步做的所有事都是为这一张铺路：in-process 的 `eval`、常驻能保留 `def` 的命名空间、无沙箱、无审批门禁、"不重建消息"从而保留错误现场。但这些加起来**至今一次都没有真正用过**——工具能改文件、能跑 shell、能 eval，但没有任何东西验证过"改内核"这个动作是可行的。

**Blocked by:** 02 (replay 是这张的安全网；先有恢复能力，再允许破坏)

**Status:** ready-for-agent

- [ ] agent 通过 `eval` 重新定义一处内核行为，下一次对话就体现改动，进程不重启
- [ ] 改动的过程与结果被记下来：改了什么、观察到什么、是否回滚
- [ ] 改坏之后，重启进程并从日志 replay 出一段可继续的对话（依赖 02）
- [ ] 明确写下一条边界：哪些改动是安全的、哪些一改就回不来（例如改坏了 `eval` 工具自己的实现）
