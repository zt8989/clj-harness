# 03 — `$ARGUMENTS` 替换

**What to build:** `/greet 世界` 里的 `世界` 是这次调用给命令的参数；正文里的 `$ARGUMENTS`
在注入时被替换成它——整串、原样。没写 `$ARGUMENTS` 的命令，正文**逐字节不变**。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 替换只发生在**命令正文**：不发生在人打的那条消息，也不发生在技能正文。
- [ ] 参数为空时 `$ARGUMENTS` 替换成空串（命令仍加载，正文其余部分照旧）。
- [ ] **不做展开**：`/run $(whoami)` 让正文里出现的是字面量 `$(whoami)`，不执行任何东西。
      这是文本置换，不是 shell，也不是格式化字符串。
- [ ] 参数里的 `$1`、`$&`、反斜杠对替换结果没有特殊含义；替换是一次性的（替换进来的文本不再被扫一遍）。
- [ ] 一条命令在一个回合里被加载两次，仍只贡献一份正文、且替换用的是同一次的参数。
