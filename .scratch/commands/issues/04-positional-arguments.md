# 04 — 位置参数 `$1` `$2` …

**What to build:** `/greet 张三 李四` 让 `$1` 是张三、`$2` 是李四。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `$1`…`$9` 各自对应按空白切分的第 n 个参数；`$ARGUMENTS` 仍是整串，两者可同时出现、互不干扰。
- [ ] 越界（要 `$3` 只给了两个）替换成**空串**——不是原样保留、不是报错。少给一个参数是日常，
      不是配置坏了；这一档与「AGENTS.md 在但读不出来就停 run」是两条纪律。
- [ ] 参数切分与 `$ARGUMENTS` 的整串取自**同一次**切分结果：两处各切一次就会对不上。
- [ ] `$0`、`$10`、`$` 后面跟非数字：**原样保留**。谁也没写过这种形状，替它猜就是把猜测写成事实。
- [ ] 引号不分组：`/greet "张 三"` 是两个参数。切分规则写在测试名里，不靠注释口口相传。
