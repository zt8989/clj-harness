# 05 — 守卫与拒绝词汇

**What to build:** 这门语言**说得出自己哪里错**。逐条打一个畸形载荷，每条都得到一句**指名**的话，
并指出下一步——因为模型手里只有这些话术，没有第二份文档。清单照 omp 的 `Common failures` 那一节。

**Blocked by:** 04（两个模式共用一个 `edit`）——动作齐全之后才写得准：写到一半的拒绝表会在下一票里
过期。

**Status:** ready-for-agent

## 要落的话术（每条一个用例）

| 情形 | 话要说清什么 |
|---|---|
| 段头缺失 / 畸形（缺 `]`、路径为空） | 段头的形状，以及「一段一个文件」 |
| 未知锚点（4 个字符但不在表里） | 它**从来不是**锚点；去 `read` / `grep` 拿现行的 |
| 锚点在文件外 / 在**没展示过**的行 | 先读那几行——这是「已展示行」那条规矩的话术（今天已有，改成载荷版） |
| 区间逆序 | 两个锚点的先后 |
| 区间/动作**重叠**（同一个原始锚点被两次指向） | 哪两处撞了 |
| body 为空（带冒号的 `PUT` 没有 `+` 行） | 是「删除」就写 `CUT`，或者给一行 `+` |
| 给不吃 body 的动作配了 body（`CUT` / paste / `REM` / `MV` 后面跟 `+` 行） | 哪个动作不吃 body |
| 未知寄存器 | 本会话有哪些具名寄存器 |
| 无名 paste 而没有一次明确的 `CUT` | 匿名寄存器是**批内**的、开始时是空的 |
| `N*`（块）三形 | 本仓按行寻址，请给显式区间（spec 决策 3） |
| **统一 diff 污染**（`@@`、`-旧行`、`*** Begin Patch` 之外的信封） | body 是**最终内容**，不是 diff |
| 逐字节无变化 | 改了等于没改 |
| 同一个 no-op 重复到第三次 | 循环守卫：停下来，去看别的地方（omp 有这条） |
| `REM` / `MV` 冲突、非法目的地 | 目的地怎么了 |

## 要做的事

- **一份实现，两处使用**（spec 决策 12）：载荷内的重叠/逆序判定与批计划器跨调用的同一类判定
  **共用同一个函数**——今天 `cap.hashline.replace` 里那套区间算术搬进载荷解析，批那一侧调它，
  不许出现两份「什么算重叠」。
- **解析器只报第一个错还是报全部**：定成**逐段收集**（多段时一次把每段的错都给出来），
  段内**第一个错即停**——理由写在函数 docstring 里，并有用例。
- **话术的形状**：一句「哪里错」+ 一句「怎么办」，与既有工具的拒绝话术同一风格
  （`harness.cap.hashline` 的 `refusals` 已经是这套先例）；**不出现内部标识**（表名、函数名、异常类名）
  ——这是本仓已有的规矩。
- **no-op 守卫的状态住在哪**：同一个会话里同一个文件的连续 no-op 计数，是会话状态
  （与寄存器同一处，按键分家）；写清它什么时候清零。
- **错误路径下不许有副作用**：所有拒绝都发生在**任何写**之前（票 02 的 fail-fast 是前提，
  本票补最后的边角：`REM` / `MV` 的校验也在写之前）。

**跟着改的**：`edit` 的描述末尾补一小节「常见失败」，与话术一一对应（模型读到的是同一张表）。

## 不要做的事

- 不做 omp 的「宽容解析」（它对常见手滑有有限的修复与警告）。本仓的立场：**能修的只有一种，
  就是没有歧义的那种**；其余指名拒绝。这条要写进 spec 的落地记录。
- 不新增工具、不新加协议帧、不动记录。

## 验收

- [ ] 上表**每一条**都有一个用例，断言：`error` 为真、话里含关键短语、话里**不含**内部标识
      （`grep` 一份禁词表：表名、`.clj` 路径、异常类名）
- [ ] 「怎么办」那一句指得到**具体动作**（把锚点从 `read` 里拿来、用 `CUT` 删、给显式区间……），
      且这套话术与描述里那一小节**逐条对得上**（有一处机械检查：话术的关键短语出现在描述里）
- [ ] 重叠/逆序只有**一份**判定实现：`grep -rn "defn.*overlap\|->overlap" src/harness/cap/hashline` 一处；
      批那一侧与载荷那一侧各有一条用例走同一个函数（可以用 `with-redefs` 数调用）
- [ ] 多段时一次给出**每段**的错；段内只给第一个错（两条用例）
- [ ] no-op 三连升级有用例，且它**不影响**合法的连续编辑（一次改对之后计数清零）
- [ ] 所有拒绝都发生在写之前：对每条话术用例断言目标文件**逐字节未变**
- [ ] `timeout 900 clojure -M:test -m harness.test-runner` 通过，失败**用例名**与基线一致
