# 02 — 一次调用的答案有上界：按字节、留尾部、带省略量与溢出路径

**What to build:** 前台 `bash` 的答案**不再没有上界**。命令打出来的东西超过预算时，**整份**（一行不丢）
落成配置家里的一份记录，答案是**尾部 + 一行「省略 N 字节」+ 那个路径** —— 模型接着用 `bash`
（`tail` / `grep` / `cat`）、`read`、`grep` 读完它。低于预算时**逐字与今天相同**：没有路径、没有省略量、
**一个字节都不落盘**（`echo hi` 不该因为这条特性多绕一次）。

参考规格在这一处比本仓细，三条都收下：**按字节不按行**（一行 100KB 的 JSON 撑爆按行方案）、
**截断必带省略量与溢出路径**、**stdout 与 stderr 各自计数**。`clip` 不动（它是 `eval` 的：字符数、
留头部；而测试的头部全是 `Testing …`，要读的在尾巴）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## 要落地的判断

1. **一个 `def` 决定预算**，描述里插值（`bash-default-timeout-ms` 的先例）。
2. **留尾部，不留头部**：模型要的是「最后说了什么」，而整份在记录里，`grep` 拿得到中间。
3. **两个流各自一份预算**：一条 stderr 只有一行、stdout 有几万行的命令，那一行不许被挤掉。
   记录的字节顺序与今天的答案一致（stdout 然后 stderr），省略量**分别**报。
4. **记录是一份文件，一条寿命**：路径只在一处拼（`harness.cap.jobs` 今天那个函数就是这一处的先例）、
   住配置家（围栏自由，所以 `read` / `grep` / `bash` 都够得着）、**随进程退出消失**
   （退出钩子一并收），不进 jsonl / sqlite / AG-UI / 轨迹。
5. **末行仍是既有的那一条**：`[exit N]`，到点时是既有的那句「到点被停掉」—— 记录的最后一行与答案的
   最后一句话是同一件事，不发明第二种写法。
6. **前台没有排空线程**：写入者就是这一次调用自己（它拿到 `out` / `err` 时命令已经结束），
   所以「一行不丢」在这一处是顺序写下去，不是异步排空。

## 验收

- [ ] `bash {command: "seq 1 200000"}` → 答案是**尾部** + `[truncated: 省略 N 字节]` + 一个路径；
      `bash {command: "wc -l < <path>"}` 答 200000（**一行不少**）；`read` 与 `grep` 读同一个路径
      **不挂审批**
- [ ] `bash {command: "echo hi"}` → 逐字 `hi`，答案里没有路径、没有省略量，**没有任何文件被写出来**
- [ ] 一条 stdout 很大、stderr 只有一行的命令：那一行 stderr 在答案里，省略量只报 stdout 的那份
- [ ] `bash {command: "seq 1 5000; sleep 300", timeout: 1000}` → 记录里是到点前打出来的那些行，
      末行是既有的「到点被停掉」那一句；那条 `sleep` 的进程不在
- [ ] 省略量是**字节数**：一条打了 `N` 字节的命令，答案里的省略量与记录里能对出来
- [ ] 记录随进程退出消失（退出钩子那一处的既有用例扩一条）
- [ ] `node scripts/test.mjs --backend` 全绿（失败用例名与基线一致）
