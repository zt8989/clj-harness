# 04 — 展开是拉：折好的一轮点开才取回它的原始步骤

**做什么**

折好的轮带着它的 `seq` 区间（票 01 的 `:from-seq` / `:to-seq`）。用户点开它时，按这个区间**拉那一轮的
原始 entries**，把步骤**原地**插回去。

这是 ADR 0003 决策 4 的原话——**更早的历史是拉，不是推**——本票只是让展开也走同一条路，而不是假装数据
早就在手里。

**做法**

- 复用票 02 的那套寻址（字节游标 / 反向读），加一个「按 `seq` 区间取回来」的形状：给区间，答那一轮的原始
  entries（`reasoning`、`tool-call`、中间的 assistant 消息一样不少）。
- 取回来的必须与**直读整份**得到的那一轮**逐字节一致**——这条是这一票的判据，不是「看起来一样」。
- 窗口要记住「这一轮已经展开过」：再次折回去**不重新拉**，而且刷新之后不因为投影又把它折起来而丢掉已展开
  的事实（或者明说：刷新后回到折好的样子，展开是一次阅读动作，不是状态）。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 区间读答回来的那一轮，与整份直读得到的那一轮**逐字节一致**（`test/harness/edge/replay_test.clj`
      或 `http_test.clj`），包含边界：区间两端、一轮只有一条消息、一轮完全没有文本。
- [ ] 区间读只读那段（票 02 的按字节判据同样适用）。
- [ ] 窗口的合并语义：折好的轮被展开后**原地替换**（位置不变、不新增），展开过的再折回去不重新拉；
      `ui/test/suites/` 有对应的用例。
- [ ] 一个还在跑的会话：正在被写的那一轮**不可展开**（它本来就没折），也不会因为展开请求而把半成品冻住。
- [ ] 区间读碰到坏的/不存在的区间时**说出来**，不静默答一个空轮。
