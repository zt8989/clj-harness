# 02 — 投影图：每条状态由记录的哪一行推出

**What to build:** 一张表，对库里**每一张表、每一列**写下它由记录里的**哪一种行**推出，或明确判它「不可投影」并给理由。这是消费者（票 03）与重建（票 05）的实现契约，也是这一页最该先钉死的东西——写它的过程会暴露「哪几列其实推不出来」。至少要覆盖：`projects`（身份）、`sessions`（归属 / `archived` / `title` / `last_sent_at` / `last_project_path`）、`todos`。判「不可投影」的今天看到的候选：hashline 的锚点归属与快照（铸造出来的状态，不在记录里）、`session_claims`（本进程的 claim，进程事实）。同时定下投影的 offset 用什么：**记录行号**（与 ADR 0003 决定 9 同一个数）。

**Blocked by:** 01 — 边界先定，才知道「可投影」是允许的。

**Status:** ready-for-agent

- [ ] 表落进 `spec.md`，每张表/每一列都有「来源行（哪种行、哪个字段）」或「不可投影 + 理由」
- [ ] 至少点名一样「记录里有、但故意不投影」的（对话正文本身），并说清判据
- [ ] offset 的定义写下来（记录行号），与窗口的 seq 是同一个数
- [ ] 「不可投影」那几样各自写明「随库丢失」，不留给票 05 去猜
