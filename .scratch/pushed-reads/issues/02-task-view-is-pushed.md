# 02 — 右栏任务视图两段由推的（删掉那个 `setInterval`）

**What to build:** 右栏开着时，本会话的**后台作业**与**子代理**两段不再每秒去问：作业起/停、委派开跑/跑完，
行自己在栏里出现和落定，**网络上一条重复的读都没有**。栏不画（窄窗 `display:none`）或卸载，订阅就断，
服务端不为没人看的会话建帧。运行中那一行的秒数照旧在长，但那是一个**只喂渲染的本地钟**，不产生任何请求。

这是 `events.mux` 的**第三种帧**（会话事实帧，建议 `type: "tasks"`）与它的第一个读者。跟着要改的两处：
客户端现在按「是不是窗口帧」二分（第三类会掉进 run 订阅里被丢掉）⇒ 改成按类型分发；
订阅集合现在从窗口 + run 两处拼 ⇒ 变三处，否则握手 URL 不会为这场会话声明，帧推不到。

那一栏读的东西由**票 01** 换过来源（作业的身份活过进程）；这一票只负责**把那份答案推出去**，
不改变它说的是什么。

**Blocked by:** 01 — 票 01 换的是那一栏**读的来源**，先把来源钉稳，再把它推出去；否则推的是一份
下一票就要改的东西。

**Status:** ready-for-agent

- [ ] 栏开着看一整场 run：`performance.getEntriesByType('resource')` 里 `/jobs` 与 `/api/subagents`
      **不再增长**；栏关掉之后再等 6 秒，两条计数一动不动（右栏特征那次走查量的是「关栏 111 → 6 秒后仍 111」，
      这一条要的是「开着也不动」）。
- [ ] 起一条后台作业：行出现（`[running]`、秒数在长）；它结束（跑完，或人按 ■ / 模型 `job_kill`）：
      行变它自己的末行，**期间没有一条读**。
- [ ] 委派一个子代理：行出现「运行中」；它跑完：「已结束」，**期间没有一条读**。定义被删掉的那种行照旧
      「只画名字与状态」。
- [ ] 运行中那一行的「已跑 N 秒」照旧在长，而那一格**不产生任何请求**（本地的钟）。
- [ ] **变了才推**：某一行没有任何变化的整段时间里（比如一条 `sleep 60` 的作业在跑而什么都没发生），
      socket 上**不发任何东西**——不是「发了、客户端不重画」。量的办法是数帧，不是数请求。
- [ ] 栏不画（767px 的 `display:none`）或卸载 ⇒ 那一场的订阅结束（服务端 `watch` 归零）；再打开 ⇒
      当前这一刻的两段一次到位（不空一拍、不闪空话）。
- [ ] 一页同时跟着两场会话时，帧按 `threadId` 落到**正确的那一场**，不串场。
- [ ] **刷新页面两段照旧在**（票 01 之后作业是持久的，子代理本来就持久）；而「还在跑」那条线照旧诚实：
      重启之后一律不再说「运行中」。
- [ ] 后端 `clojure -M:test -m harness.test-runner` 全绿；`cd ui && npm test` 与 `npm run build` 全绿。

**落地时要记下来的**：这一帧**没有游标**（断线重连拿到的是一份当前的两段，不是增量）——与 `events.host`
同一条理由：它问的是「现在是什么样」。以及服务端只在**作业起/停、委派开跑/结束**时建帧，
不在每一行作业输出落盘时建（作业的每一行输出落的是它**自己的**记录，不进本会话的帧）。
