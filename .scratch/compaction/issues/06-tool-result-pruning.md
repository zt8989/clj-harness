# 06 — 先免费：工具结果剪枝，剪完重新测量

**What to build:** 超大**工具结果**先被**中间砍掉**（保留头尾）——不调模型、不花钱；剪完**重新测量**
一次压力，回到安全区就**跳过摘要**。原始事件仍在记录里，回执记下替换前后的字符数。剪枝只是本地
字符串切片，消息还是那条消息，工具调用与结果的配对关系一点没变。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 超大工具结果被中间省略、保留头尾；工具调用与结果的**配对关系不变**
- [ ] 剪枝是**确定性**的：不调模型
- [ ] 剪枝之后**重新测量**；压力已回安全区则**跳过摘要**（有一次模型调用没有发生）
- [ ] 每次替换在记录里留**收据**：被遮蔽的原始事件、新追加的替换事件、共享的调用 id、
      替换前后的字符数
- [ ] 收据里的字符数按 **Unicode code point** 算（不是 UTF-16 code unit），切割边界**不劈开代理对**
- [ ] 总减少量可读出（汇总到一次剪枝的结果里）
- [ ] 剪枝服务**可以缺席**（没装就直接进摘要）：它不完备——只动工具结果里的文本主体，压不掉用户
      粘贴的一长段、也压不掉信封
- [ ] 端到端：一条巨型工具结果触发剪枝而**不是**摘要；剪到安全区之后摘要没发生
- [ ] 与 05 的溢出路径对得上：剪枝压不动时溢出路径仍能更激进地缩减头部
- [ ] 离线全量 `harness.test-runner` 全绿
