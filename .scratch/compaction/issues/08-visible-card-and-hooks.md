# 08 — 看得见：压缩那张卡与两个 hook

**What to build:** 会话里画一枚**可折叠的压缩标记**（遮蔽了几条、值多少 token、什么时候），能展开读
**原文**；上下文圈画出 **0.7 阈值**与 **0.16 保留**两条界线，能看出当前压力落在哪个区间；每次压缩
前后 **`:pre-compact` / `:post-compact`** 真的触发并落审计行。

赌的是那句「答不答得上来『刚才丢的是什么』，取决于压缩有没有留下账」——账在记录里已经有了，这张票
把它画到人眼前。

**Blocked by:** 01, 03

**Status:** ready-for-agent

- [ ] 会话里出现一枚压缩标记，说清遮蔽了几条、值多少 token、属于哪一轮 / 哪次手动
- [ ] 标记**可折叠**，展开看得到被遮蔽的**原文**（原文一直在记录里，这里只是把它取出来）
- [ ] 上下文圈画出阈值（0.7）与保留（0.16）两条界线，能看出当前压力在哪个区间

- [ ] 每次压缩前后 `:pre-compact` / `:post-compact` **各触发一次**并落审计行；两个点仍是**观察者**
      （不阻断），退出码不拦压缩
- [ ] 文案走既有词表（中英各一份），没有裸字符串

## Comments
