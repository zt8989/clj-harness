# 03 — 压缩本身：一次模型调用，四条记账

**What to build:** 人（或一次管理动作，入口是 `/compact`）可以**手动**压一次。先算出**逐字保留的
尾部**（0.16 × 窗口），用**一次独立的模型调用**把前面的头部压成摘要；然后按顺序写四条记账：
`start` → `summary` → 替换用的消息 → `end`（**`end` 写在最后**，锁才成立）。若头部含**会话开场**，
重建开场与重建 system prompt 必须是**同一次**的事。没有可压范围时**一个字都不写**。

这是这条脊柱：一次压缩让**记录长四条、模型视图短一段**，原文一条不少地留在原处。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `/compact` 之后，下一次模型调用看到的是摘要 + 逐字保留的尾部；人看到的还是原文
- [ ] 一次压缩让记录**恰好长四条**（三条记账 + 一条替换消息）；只长三条说明漏了 `end`
- [ ] 摘要是**一次独立的模型调用**，它自己也留一对 `model/start`·`model/end`；摘要调用的信封
      （provider、model、用量）记进记录——「是哪个模型写的这段摘要」有持久答案
- [ ] 保留预算按 0.16 × 窗口算；保留尾部里遇到**不可分单元**时整条保留、不切开
- [ ] 没有可压范围（全部内容都在保留尾部里）时**不写任何东西**，不是写一对空 `start`/`end`
- [ ] 头部含会话开场时，压缩后**开场与 system prompt 在同一步重建**，两者来自同一时刻；旧开场还在
      时按既有去重规则自然不重复
- [ ] 压缩不改变任何原始消息：被遮蔽的行逐字符还在记录里
- [ ] 手动压缩在**轮次之间**跑，不依赖正在跑的一轮，也不消耗溢出重试预算
- [ ] 被遮蔽范围含活动、缺失、位置反转或不平衡时**拒绝**（说的是位置，不是数值）
- [ ] 记账行的形状与读侧一致：`context/compacted` 事实行，`:shadowed` 是**按 surface 顺序**的被遮蔽
      节点 seq、`:summary` 是摘要文本（读法是 `replay/compaction-facts` / `replay/compacted-messages`）；
      第二次压缩要**点名上一次的摘要节点**（用那次事实自己的 seq），不是它替代掉的那条原消息
- [ ] 选范围时读的是**带 seq 的 surface**（条目 + 已有压缩事实），不是只有文本的 `sessions/messages`
      ——否则拼不出合法的 `:shadowed` 清单
- [ ] 压缩写进记录的那一刻，**活动会话的压缩事实跟着刷新**（今天 `sessions` 只在建会话时读一次
      `:compactions`；不刷新的话模型还会拿到没压过的历史）
- [ ] 离线全量 `harness.test-runner` 全绿

## Comments

2026-09-23 — 写侧核心与入口已落地：

- 已做：`plan`（留出 0.16×窗口的尾部，**按节点边界切**，节点就是最小单元）、`lock-active?`、
  `perform!`（start → `context/compacted` → end；摘要抛异常也写 end 并带 `:error`）、
  `POST /api/threads/<stem>/compact`（一次真实模型调用 + 刷新活动会话的压缩事实）。
  测试 `compaction-run-test` 8 例，含一条跑通整条写路径的路线用例；全量 1164 tests / 13281 assertions。
- 与票面的偏离：写**三条**记账行不是四条——摘要文本与范围同在一张 `context/compacted` 事实行上，
  替换消息由投影（`replay/model-nodes`）现折；本仓没有独立的 surface 结构可挂一个 `replace`。
- **仍缺一条**：头部含**会话开场**时重建开场。今天开场是会话出生时写下的 `opening` 条目，遮蔽它
  就会把指令块从模型视图里拿掉。正确做法是**开场不参与压缩**（头部从开场之后的节点开始），
  留给续做。
