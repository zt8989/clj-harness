# 04 — 自动：每一步开始前，过 0.7 就压

**What to build:** 从这一步起压缩**自己发生**。每个**轮**开始、派生请求之前量一次压力；**≥ 0.7 ×
窗口**就压一次，没到就什么都不做。阈值与保留比例进配置（默认 **0.7 / 0.16**；保留必须**严格小于**
阈值，否则加载时指名报错——否则压缩永远压不动任何东西）。自动压缩归属于**当前未结束的轮**。

**Blocked by:** 01, 03

**Status:** ready-for-agent

- [ ] 阈值比例默认 **0.7**、保留比例默认 **0.16**，都可配置；保留 ≥ 阈值时**加载即指名报错**
      （能在加载时判定的错就在加载时炸）
- [ ] 每个轮开始、请求派生**之前**检查一次；过阈值就压，压完接着派生
- [ ] 没过阈值时**零副作用**：不写记账、不调模型、不花一次刷盘
- [ ] 自动压缩的记账事件带上当前轮的号（数字，表示归属一个未结束的轮）；人不会看到一个莫名其妙
      中断又冒出来的新轮
- [ ] 压不动（没有可压范围）时**不写任何东西**，这一轮照常继续
- [ ] 阈值判定用的窗口是**这一次调用自己**记的 `:context-window`；换 model（窗口不同）时阈值随之改变
- [ ] 端到端：跑一段长会话，压力过 0.7 时记录里出现一次完整压缩，模型视图变短、原文全在
- [ ] 只报告的那张票（01）的行为不回归：没到阈值时读数照记，行为不变
- [ ] 离线全量 `harness.test-runner` 全绿
