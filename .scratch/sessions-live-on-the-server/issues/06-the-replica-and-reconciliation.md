# 06 — 副本：窗口、补页、刷新

**What to build:** 浏览器是**只读副本**，手里是一段**窗口**：`{entries, baseSeq, hasMore, revision}`。
开窗拉**尾页**；增量来自 feed（票 05）；更早的由**「显示更早」那颗按钮**一页一页补。**断档只重建
已加载窗口**，不重读全史。**刷新走内存**（落尾页）。用户正在打字 / 滚动时，对账与补页都不许动它们。

决策见 `docs/adr/0003-the-feed-is-a-window.md`。

**Blocked by:** 03, 05

**Status:** ready-for-agent

## 要落地的判断

1. **窗口的形状**：`{entries, baseSeq, hasMore, revision}`。**`revision` 不是消息序号**——它是「窗口变过
   几次」的计数（参考实现里每次 `publish` 加一），用来判断一次推来的变更是不是接在副本已有的状态上；
   消息序号是另一回事。两个数混用是这一票最容易犯的错，要分开命名、分开测。

2. **「续不上」的三种情形，两种处置。** 要分清**补一页**与**重开**：
   - **序号缺口**（推送断了、漏了几条）⇒ 拉一页**尾巴**把窗口对齐（`since` 语义），保留用户已经滚到的
     位置；
   - **重连** ⇒ 同上（参考实现就是这么修的：「通过 tail page 修复重连或 seq 缺口」）；
   - **generation 作废**（会话被放掉、认领易主、地址被替换）⇒ **重开**尾页，回到最新。
   这两种处置的触发条件要写下来，并且各有一条用例——把它们合成一种，就等于要么丢用户的滚动位置，
   要么让副本停在一段已经作废的窗口上。

3. **「显示更早」是一颗按钮。** 位置（会话栏里的位置要定）、态（补页中复用**同一个** loading 位——
   参考实现的 `loadingOlder`，避免连点出两页，也避免两页并发回来乱序）、到头了（`hasMore` 为假）
   就不画。它**不是**自动加载：自动加载全史就是「全量推送」换了个方向，ADR 0003 决策 4 挡的就是它。

4. **跳转要不要做。** 参考实现有 `loadThrough(seq)`（从轨迹点回某一轮，一页 200 循环拉到覆盖目标）。
   **倾向：本票只做「补一页」**，跳转是另一张票——它需要一个「目标 seq」的入口，而那个入口属于轨迹视图，
   不是副本自己的事。若要做，要写清参考实现踩出的那两条：重复调用**下调**共享目标、一页没有进展即停。

5. **副本超前**（原票 05 的判断 3）：它有服务端不知道的东西。本特征之后应当**不可能**（客户端不再是
   作者）；构造一个要说出来，不许静默丢。

6. **打字 / 滚动**：对账与补页发生时，**选中位置、滚动位置、输入框里未发出的字**都不许动。注意补页是
   `prepend`——它天生把内容往下推，所以「滚动位置不动」要靠**锚定**（补页前记下锚点，补页后还原），
   不是「什么都不做」。这一条要有走查证据，用例测不出来「渲染看不到布局」那一格。

7. **刷新走内存**（原票 05 的判断 1，保留）：记录允许落后，走记录 ⇒ 刷新看到的是**更早的那一版**，
   而屏幕上刚才还显示着更新的内容 ⇒ 用户看见「会话丢了尾巴」，而它其实没丢。窗口化之后刷新就是
   拉尾页，落点天然是最新。

8. **`node scripts/dev.mjs --scripted` 是硬要求**（动过 `ui/src/`），而且这次要走查**两个**场面：
   刷新回同一场，以及点一次「显示更早」。

## 验收

- [ ] 打开一场长会话：屏幕上先只有**尾页**，顶部有「显示更早」；点一下多一页，且**到达的是紧邻的那一页**
      （有用例；走查抓一张）
- [ ] `hasMore` 为假时那颗按钮不画（有用例）
- [ ] 连点 / 补页进行中：只有一次补页在飞，`baseSeq` 前移一次（有用例）
- [ ] 补页时正在打字的位置**不动**；滚动位置也不跳（走查证据）
- [ ] 构造一个「内存比记录新」的状态，刷新后看到的是新的那份（有用例）
- [ ] 构造一个序号缺口 ⇒ 窗口**补一页对齐**，不重读全史（有用例）
- [ ] 构造一个 generation 作废 ⇒ 窗口**重开**，并且**说出**它重开了（有用例）
- [ ] 副本超前 ⇒ 说出来，不静默丢（有用例）
- [ ] `node scripts/dev.mjs --scripted` 走查：一轮里改一次模型、刷新、看它还在同一场；再点一次「显示更早」
