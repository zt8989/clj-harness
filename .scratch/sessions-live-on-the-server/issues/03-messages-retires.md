# 03 — 输入面：`messages` 退役

**What to build:** run 的输入不再是浏览器递上来的消息列表。剩下五样按 ADR 决策 9 那张表逐条落：
`threadId` 留（**铸 id 收进「新建会话」这个动作，服务端铸**）；`runId` **服务端铸**；`provider`
**动作化**（改会话档，请求里退役）；`context` **归会话状态**（出生时进历史）；`resume` 留
（`interruptId` 也留，认不出就拒）。前端 adapter 的**写侧**跟着改。

**Blocked by:** 01；`.scratch/session-after-refresh` 票 05（跨特征：没有那条门，两个标签页就往同一场里塞两条 run）

**Status:** ready-for-agent

## 要落地的判断

1. **不收 `messages`**：`ag/inbound`（`edge/ag_ui.clj:369`）今天把「客户端消息」当作历史的全部。
   改成：历史来自内存那份，客户端的**这一条新消息**（动作的载荷）追加其后。要定的是**动作的载荷形状**
   （一条消息？还是「发这条」这个动作 + 它带的字节）——它进了 AG-UI 协议的 `messages` 字段还是另起一个字段，
   这一票要选一个。
2. **`threadId` 与「新建会话」**：今天任何客户端铸的 id 都被容忍（库里没有就照跑，由「第一次跑起来」登记）。
   改成一个**动作**：新建 → 服务端铸 id → 交回；此后所有动作只带服务端给的 id，**认不出就报错，不静默建**。
   它顺手解掉 ADR 0001 决策 3 在打的那个补丁（挂载铸一枚新 id ⇒ 多一条空会话）。
3. **`runId` 服务端铸**：客户端能命名 run ⇒ 能撞 id、能重放。注意 `context-frames` 的卡 id 是
   `runId-openN`（`http.clj:1026`），**重建要同名同 id 回来**——而那份稳定来自**记录**（帧里带着
   `runId`，重建读的是记录），不是来自「再铸一枚一模一样的」。所以铸完之后它必须**进记录**。
4. **`provider` 动作化**：今天它是三档最上面那层（`current-provider`，`providers.clj:1164`），
   **每轮背着**；同时 `session-configure` 又写会话档（`update-selection!`，`:1146`）——两条路并存。
   动作化 = 选择器的改变走后者，请求里那一层退役；客户端**显示**服务端报的当前档（`active-provider`，`:1174`）。
5. **`context` 归会话状态**：今天它是客户端每轮送来、渲染成一条尾随 user 消息（`context-message`，
   `edge/ag_ui.clj:342`），而 `rebuild` 又把它交回客户端（`http.clj:1915`）——它本来就属于会话。
   出生时构造一次、进历史，此后不在输入面里。**它进历史 ⇒ 它在缓存前缀里 ⇒ 每轮不重算**（验收 6 的前半）。
6. **`resume` 不动**：`resume-decisions`（`http.clj:684`）今天就是「动作 + 服务端自己的内存」
   （认不出就硬报错）。这一票只把「`messages` 退役之后它还剩下什么」写清楚，不改行为。
7. **前端 adapter 的写侧**：`sessionHistory`（`app.tsx:207`）的 `load` 已经在读服务端，`append` / `update`
   已经是 no-op。要改的是**送回**：不再把累积的 `messages` 送回去。这一票是唯一卡着前端的，所以
   `node scripts/dev.mjs --scripted` 走查是硬要求。

## 验收

- [ ] 一轮跑完，客户端发出的下一个请求里**没有** `messages` 那份累积历史（有用例，最好是真浏览器走查
      抓一次请求体）
- [ ] 服务端继续跑用的是内存那份；它与上一轮记录里 `message` 行 submitted 侧**逐字节相同**（与票 01 同一条）
- [ ] 新建会话：id 由服务端铸并交回；此后用一个不存在的 id 发动作 → **按名字报错**，不静默建（有用例）
- [ ] `runId` 服务端铸；同一场同一轮重建两次，卡的 id 相同（有用例）
- [ ] 换模型是一次**动作**：一次改动之后每一轮都用它；请求里没有 `provider`（有用例）
- [ ] `context` 出生时进历史一次；此后三轮不再出现（有用例）
- [ ] `resume` 的既有用例全绿（认不出就拒那条不变）
- [ ] `node scripts/dev.mjs --scripted` 走查：真浏览器里发一条、看它跑完、刷新回同一场
