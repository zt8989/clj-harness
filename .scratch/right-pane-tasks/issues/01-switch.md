# 01 — 右栏的开关：能开、能关，打开是任务视图

**What to build:** 右侧那一栏有了自己的开关，做法照左侧栏那一对：**收起**那颗画在右栏自己头部的**前缘**，
**打开**那颗是页面**右上角**的浮动一颗、只在栏关着时画。点开 → 右栏**并排**出现（与今天那面镜子同一列、
同宽、同 `md` 断点），里面是**任务视图**：上面一段「子代理」、下面一段「后台任务」——这一票先只画两段的
标题与各自的空话（数据在 02 / 03）；点收起那颗 → 主对话复原。点主对话里那张 `agent` 卡照旧开这一栏，
直接进镜像那一态。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## 形状

- **状态是一个三态值**，住在 `App`（`ui/src/app.tsx`）里今天 `subagentView` 的那个位子：
  `null | {:kind "tasks"} | {:kind "mirror" :threadId .. :subagent ..}`。
  打开那颗只写 `{:kind "tasks"}`，收起那颗只写 `null`，`agent` 卡只写 mirror，镜子的返回写 tasks。
- **开关是 `components/sidebar-toggle.tsx` 那条契约的右侧版本**，不是一个像它的新东西：
  - **收起**：`PanelRightCloseIcon`（对 `PanelLeftCloseIcon`），画在**右栏头部的前缘**——与左栏把收起
    画在自己的 brand 行尾端同一条道理：说出「这一栏是什么」的那一行，就是出口该在的行。
  - **打开**：`PanelRightIcon`（对 `PanelLeftIcon`），画在**页面右上角**、`absolute`／浮在主对话之上、
    栏关着时才画——左栏那一颗是「折起来的列在窄窗口是 `display:none`，得有个东西留在外面」，右栏
    同理（它在 `md` 以下整个不画）。
  - 两处**共用同一个导出的 id** 与 `aria-controls`，`aria-expanded` 说它现在开着没有，两态各说自己
    要什么（一条说了「打开」却画着「关闭」的图标，是这个仓里最容易被读到的一类谎话）。
  - **右栏与这一对同生共死**：`md` 以下右栏本来就不画（`.scratch/subagent-view` 05 的决定），那时两颗
    也都不画——一条点了没反应的开关比没有开关更坏。
- **右栏的骨架**（这一票）：两段标题 + 两段空话。宽度、`border-s`、`shrink-0`、并排不覆盖这些字
  **照镜子那一版**，别另起一套。
- 关掉**不记**「上次看的是哪个」：再打开是任务列表。
- 两段标题与空话都走 i18n（`ui/src/locales/{en,zh}/` 那套），两套都要在，别硬编。

## 决策

- **一列两态，不是一个新面板。** 镜子的组件、它的跟随通道、`key` 是子会话 id、关掉就挂断——一个字
  不改。这一票只改**谁把它挂上**，以及它在没有子代理被选中时显示什么。
- **照抄左侧那一对，不发明第三处。** `sidebar-toggle.tsx` 的头注释把理由写全了（一件契约两个地方、
  共用一个 id 才查得动、状态是 transient layout preference 所以不持久化）——右栏这一对读同一段话，
  别把这套理由重写一遍。
- **镜像头部那颗 X 退场**：它与新的收起是**同一个动词**（把整栏关掉），同一个头部放两遍是两道门通向
  同一间屋。X 那个位置让给「返回列表」（03），关整栏留给前缘那颗收起。既有
  `ui/test/suites/subagent-view.tsx` 里断言 X 的用例跟着改到收起那颗上，**不许删断言**。

## 验收

- [ ] 收起那颗在右栏头部前缘、打开那颗在页面右上角；两颗的 `aria-controls` 指向同一个 id、
      `aria-expanded` 与状态对得上（`ui/test` 有一条断言，照 `sidebar-toggle` 那条先例的写法）
- [ ] 点打开：右栏出现（第三列、并排、主对话还在），两段标题与各自空话在；点收起：右栏不画、主对话复原
- [ ] 点主对话里一张 `agent` 卡仍然开这一栏、并直接进那一面镜像（`ui/test/suites/subagent-view.tsx`
      既有用例照旧绿——断言改到收起那颗，断言数不许少）
- [ ] `md` 以下两颗与右栏都不画（走查证据：窗口 767px 时右栏、右上角那颗都是 0 宽）
- [ ] 刷新页面：栏是关着的（状态不持久化，与左栏同一条）
- [ ] 中英两套文案都在；`npm test` + `npm run typecheck` 绿
