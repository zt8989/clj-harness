# 04 — 停：真的停，而且让模型知道是人停的

**What to build:** 后台任务那一行右端一颗 ■：按下去真的把那条作业（连它起的子孙）停掉，行变它自己的
末行（`[stopped]`）；并且**下一通**模型调用之前，发给模型的历史里多一条注入，说明这是**人**从面板上
停的。

**Blocked by:** 02

**Status:** ready-for-agent

## 形状

- `POST /api/threads/<stem>/jobs {job: "j1"}` → 同一个动词的第二种方法（`thread-verbs` 的 405 规矩照旧）。
  答 `{:id .. :stopped? .. :ending ..}`，与 `job_kill` 的答句同源（同一处停止、同一句话）。
  - 点名一个不存在的 id → 既有那句 `unknown-job`（**同一处出处**，别另写一句）。
  - 已经结束的作业 → `stopped? false` + 它自己的末行（与 `job_kill` 同一套话）。
- **认领的规矩分家。** `cap.jobs/stop!` 现在一步做两件事：停，**并且**把条目标成 `:told? true`
  （`job_kill` 的答案本身就是那次告知，所以之后不再发通知——那条注释与 `.scratch/job-tools` 的规矩
  都写明了）。人从面板停的这一条**不能**认领：说话的不是模型。
  - 停止这条路要有一个「谁停的」入参（模型走的照旧认领；人走的记下「是人停的」且**不认领**）。
  - 于是 `take-notices!` 那条既有机制在**下一通调用**把它送进历史，形状：
    `<job-ended id="j1" by="user">[stopped]</job-ended>` + `<command>…</command>` + 一句
    「这是人从面板上停的；用 `job_output` 读它」。
  - **标签仍是 `job-ended`**：`edge/http.clj` 的注入分类按 `<job-ended ` 这个前缀认它，界面的卡也按
    同一个标签画。`by="user"` 是属性——命令本来就在自己的元素里，不必为一个属性发明转义。
- **人按 ■ 而作业已经结束**：什么也不改（那不是人停的），走既有的 `[exit N]` 通知。
- **界面**：■ 要有在飞的状态，成功后那行刷新成末行（照 `components/session-run-stop.tsx` 那条先例：
  按下去那一瞬到答案回来之间，人得看得出「按到了」）；失败要有一句话，不许静默。

## 决策

- **注入而不是当场写一条消息。** 会话历史由服务端按轮现算（`cap.project/before-llm` 那条路），
  面板手里没有「往对话里塞一条」的权力，也不该有：注入的规矩已经有一条（每一条注入在屏幕上都有卡、
  下一轮不再重算），照它走，别开第二条路。
- **`job_kill` 的字一个不改。** 模型自己停的仍然不通知（它已经拿到答案）；这次加的是**第二个发起人**，
  不是改第一个。
- **停止是人的动作，所以它不该走审批。** 这条路由与 `cancel` 同类（`.scratch/session-after-refresh`
  07/08 先例）：人已经按了那颗按钮，再问他一次「你确定要停吗」是把一个确定当疑问。要不要 UI 上的二次
  确认，走查时看按错的代价定（作业是后台命令，代价是重跑一次）——但**服务端不设审批**。

## 验收

- [ ] 用例：`POST /api/threads/<stem>/jobs {job}` 停掉一条挂着的作业 → 记录末行 `[stopped]`，
      `stopped? true`
- [ ] 用例：人停过之后，**下一通**给模型的 history 里有那一条（`by="user"`、带命令原文、带读法），
      且**只发一次**（第二次调用不再有）
- [ ] 用例：模型的 `job_kill` 之后**没有**通知（既有规矩不许被这次改坏，逐字钉住）
- [ ] 用例：已经结束的作业被人按 → 不产生 `by="user"` 那条，状态仍是它自己的末行
- [ ] 用例：不存在的 id → `unknown-job` 那句（同一处出处）
- [ ] 用例：`job_kill` 的答句与通知的字节**逐字未变**
- [ ] 界面：■ 有在飞态、成功后那行变 `[stopped]`、失败有一句话
- [ ] 走查证据：会话里看得见那张注入卡，且它的第一行就是那条 `by="user"` 的块
- [ ] 中英两套文案都在；`npm test` + `npm run typecheck` 绿
