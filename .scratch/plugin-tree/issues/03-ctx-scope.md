# 03 — `ctx.scope`：每个会话的资源域

**What to build:** 一条原语：**为一个会话划定它的资源域**，域里注册的东西彼此看得见、跨域看不见。
今天这件事散在三处——`kernel.tools` 的会话 overlay 两轴、`cap.editing` 的按会话编辑模式、
`cap.project` 的绑定与围栏。这一票把它们收进一个概念里（dsh 的 `core/scope` 是同一件事：
「作用域注册原语」，给 agent 之间的上下文隔离）。

**Blocked by:** 02 — 守卫改成按一张声明表判

**Status:** ready-for-agent

## 验收

- [ ] scope 是一等原语，且**是数据**：能在 REPL 里看、能被断言，不是全局可变单例
- [ ] 两个会话取同一个名字，拿到的是各自那份：**每个方向各一条断言**
- [ ] 跨会话有一条**反证**断言：拿 B 会话的句柄去取 A 会话域里的东西，取不到
- [ ] 域里的注册随它的会话一起撤销（与 cordis 的 effect 是同一条路：注册即效应，卸载回滚）
- [ ] 今天那三处的**语义一字不改**（编辑模式按会话解析、工具 overlay 两轴、围栏判定）；这一票只收拢概念
- [ ] 守卫表里这一行按新角色记（脊柱），且 `kernel.*` 里没有一处再自己实现「按会话分家」
