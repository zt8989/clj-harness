# 20 — 会话投影接缝

**What to build:** dsh 有一条**投影缝**（`ctx.sessionProjections`）：注册的折子逐条增量折出一份类型化状态，
宿主读那一份；宿主**要么拿到这条缝、要么明确失败**，不许悄悄用默认值。本仓今天同一件事散在
`kernel.frames`（帧折回消息）加五份读者（`edge.replay` / `edge.stats` / `edge.context` / `edge.trajectory`
/ `edge.pressure`，各自开文件、各自折）。这一票把它立成一条缝：**折子是注册进来的**，加一个读者不动写侧。

**Blocked by:** 04 — `ctx.sessions`；05 — 会话持久化

**Status:** ready-for-agent

## 验收

- [ ] 折子注册进一条缝；**加一个消费者不动 `log!`**（本仓今天那两道订阅缝的立场不变，只是换成人人看得见的名字）
- [ ] 五个读者各读**一份**状态：不再各自开文件、各自折（今天同一个文件被折了五遍）
- [ ] 每一份折出来的结果与改动前**逐条相同**（现成的测试就是判据）
- [ ] 「读不到这条缝时**明确失败**，不用默认值兜底」有断言——静默兜底会让一个缺了服务的宿主看起来正常
- [ ] 离线折与在线折是**同一份实现**（本仓压力表今天就有这条要求，推广到全部读者）
- [ ] 只读：投影不进库、不改记录（状态 vs 记录那条边界照旧）
- [ ] 记录是「每行说它从哪来」（`:producer` 六值）这条不变，读者不必按位置猜哪一侧
