# 01 — ADR 与归属表：从四层到三类服务

**What to build:** 一份 `docs/adr/0013-*.md` 加本目录里一张**逐命名空间**的归属表：`src/harness/` 下今天的
每一个命名空间落到哪里——**脊柱**（核心服务）、**接缝**（定义 / 实现 / 消费）、**组合点**、还是不在插件树里；
每一条带判据。同时把上一轮那条「不动 harness」**标为撤销**（撤销这一动作本身要留痕迹）。

做完之后：一个从没参加过这场讨论的人，读这张表加那份 ADR，能说出「我要加的这段代码该放哪」，而且答案唯一。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
