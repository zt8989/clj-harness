# 23 — 自省：把生效的树打出来

**What to build:** dsh 那句「`dsh --profile web --dump-config`——它打出来的任何一行都能被你替换」。
这一票给本仓一件同类的东西：一条命令（或一个函数）把某份 profile 生效的**组装清单**原样打出来
——谁装的、装了什么、依赖是谁；装完之后再打一次，两份可比。**没有这一件，装配是数据这件事只是声称。**

**Blocked by:** 22 — 一份组装清单，两份 profile

**Status:** ready-for-agent

## 验收

- [ ] 一条命令打出 `web` / `headless` 两份 profile 各自生效的清单
- [ ] 打出来的每一行都能被**指名替换**：改一行，再打一次——那一行变了、其余一行不动
- [ ] 清单与实际装载的插件**对得上**：有一条断言钉着「清单里的 id 集合 = 注册表里的 id 集合」
- [ ] **不出网、不启服务器也能打**：自省是读，不是跑；它不占端口
- [ ] 打出来的东西是给人看的（含每个插件的状态与 `:inject`），不是内部结构的 `pr-str`
- [ ] 配置里的值从哪来（用户级 / 项目级 / 默认档）在输出里说得清——这是这套东西与「读一份大配置」的区别
