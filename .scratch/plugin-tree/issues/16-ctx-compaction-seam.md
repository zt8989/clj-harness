# 16 — `ctx.compaction` 接缝

**What to build:** 压缩、压力、剪枝、超窗恢复——今天它们分散在 `edge.compaction` / `edge.pressure` /
`edge.prune` / `edge.relieve-pressure` 与循环里，谁也说不全「把历史折小」这件事。这一票把它立成一条缝：
**定义**（什么时候该压、压完长什么样）、**实现**（摘要怎么调、阈值与常量）、**消费**（循环在第一次模型
调用前那一步）。

**Blocked by:** 12 — `ctx.llm` 接缝

**Status:** ready-for-agent

## 验收

- [ ] 四件事的语义逐条不变：阈值比例 0.7 / 保留比例 0.16、保留必须**严格小于**阈值、
      超窗恢复只认厂商自己那句话、`:overflow-retries` 默认 1、剪枝的 6000 / 2000 常量
- [ ] 两条事实行的形状与位置不变：`context/compacted`（`:shadowed` 按 surface 顺序、`start` 可以大于 `end`）
      与 `context/pruned`（收据记被遮蔽的事件、共享的调用 id、替换前后的码点数）
- [ ] **记录一行不删**、会话投影照旧（模型读摘要、人读原文）——两条铁律级别的判据
- [ ] 压力表的三个跑点（出生走查 / 每行落下 / 离线折）不变，锚点采用的三条判据不变
- [ ] **换一个摘要实现**（假的）跑通一次压缩——接缝成立的反证
- [ ] 剪枝那条「不调模型、不花钱」有断言钉着（这就是它与压缩的全部区别）
- [ ] 手工 `/compact` 不发那张卡、run 里压的才发——这条区别保持
