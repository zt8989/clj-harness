# 09 — `ctx.agentLoop`：循环实现契约

**What to build:** 「组装提示 → 流式调用 → 跑工具 → 再来一步」那个循环成为 `ctx.agentLoop`——它是
`ctx.agents` 契约的**一个实现**（默认那份，装配清单里有一行），不是被脊柱直接调用的函数。
换掉它，产品仍然转；不换它，行为一个字不变：**轮与步、录制内容逐字节相同**。

**Blocked by:** 08 — `ctx.agents`

**Status:** ready-for-agent

## 验收

- [ ] 循环作为装配清单里的一行装上；**脊柱里没有一处直接调用它**（没有第二条进入路径）
- [ ] 一轮 run 的记录与改动前逐字节相同（同一份脚本 provider 跑同一句话）
- [ ] 轮 / 步两级不变：`step/start`·`step/end`、`model/start`·`model/end` 的信封与数目照旧
- [ ] 「一步不跨 run、一轮可以跨 run」这条判据有断言
- [ ] 落盘时机与内容不变：工具表签名、`context/pressure` 行、压缩事实行
- [ ] 有一条断言证明「换一个最小实现（比如只回一句话的）仍能跑完一轮」——这是契约真的成立的证据
- [ ] 循环自己的失败（provider 报错、工具全挂）照旧说得清，不留半个轮
