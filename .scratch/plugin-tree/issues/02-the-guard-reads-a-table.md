# 02 — 守卫改成按一张声明表判

**What to build:** `harness.layers-test` 今天把「四层」写死在测试里。这一票把它换成**按一张声明表判**：
表说每个命名空间属于哪一类、各类允许 require 谁。表的**初值**就是今天的四层归属（行为与判据一条不变），
从此**搬一个命名空间 = 改表里一行**，而不是改测试逻辑——这是后面十几票能保持绿的前提。

**Blocked by:** 01 — ADR 与归属表；`.scratch/cordis-clj/` 01 — 一棵并存的树与它的测试门

**Status:** ready-for-agent

## 验收

- [ ] 判据是**数据**（表 + 「各类允许 require 谁」），测试逻辑只读表
- [ ] 换表之前：已有那三条断言（都归位 / 不许向上 require / 路径与名字一致）一条不少，结果与今天相同
- [ ] 换表之后：故意把某一行改错，守卫会红，且失败信息说得清「谁 require 了谁、那一类为什么不能要求它」
- [ ] 「每个命名空间都在表里」这条照旧（漏了就红）——它是这套东西的承重墙
- [ ] 表与票 01 的归属表**是同一份**（不出现两张需要保持同步的表）
- [ ] `test/harness/test_runner.clj` 的字面量没有被这次改动带歪（新增/缺失都会静默）
- [ ] 全量套件退出码 0
