# 03: 折叠状态刷新后还在，localStorage 不可用时也不许崩

**What to build:** 收成 rail 之后刷新页面，侧栏**仍然是 rail**；展开过之后刷新，它还是展开的。
偏好写 localStorage，**只有在人真的点过 toggle 之后才写**——第一次打开页面什么都不写，初始形态归
04 管。

读写的两个函数抽成纯函数（存哪个 key、值怎么写、坏值怎么回退都在这两个函数里），放进 `lib/`，
这样它们能被 vitest 直接测：本仓的 UI 测试 driver **没有 DOM**，纯逻辑能测，画成什么样只能在真浏览器
里量（既有纪律）。

**打不开 localStorage 不是错误。** 隐私模式、`localStorage` 被禁、配额满、值被外部写坏，一律静默
降级成"这台机器不记偏好"，收起展开照常能用，绝不抛异常把整页打挂——持久化是**偏好**，不是功能。

**Blocked by:** 02: 侧栏折叠成图标 rail，四个动作一个都不丢（要记住的是 02 那个 toggle 的状态）。

**Status:** ready-for-agent

- [ ] `lib/` 里两个纯函数：读偏好（键缺失/值不是 `"1"`/`"0"`/取不到 → 一律回退"展开"）、写偏好。
      key 形如 `harness.sidebar.collapsed`。
- [ ] 只在 toggle 被点击后写；首次加载（没有任何偏好）不写任何东西，形态由 04 的宽度默认决定。
- [ ] 刷新后保持：收起→刷新仍是 rail；展开→刷新仍是展开。

      渲染、不报错、不卡在半折叠状态。
- [ ] 纯函数进 vitest 套件（缺键、坏值、写后读回、抛错降级）；新增 suite 记得 bump

- [ ] 真实浏览器取证：收起→刷新、展开→刷新、坏值三种情形，截图进 `evidence/t03-*`。
