# 10 — `insert`：插在哪一行前后，锚点不动

**What to build:** 「在这几行之间加一段」是一个和「换掉一段」不同的动作，模型说它的时候也不该被迫绕成
`replace` 的写法。`insert` 收三个东西：

```
anchor:    "AAAB"          ;; 从 read 行上抄下来的锚点
direction: "after"         ;; 或 "before"
lines:     ["新的一行"]     ;; 每元素一行，[""] 是一行空行
```

插进去的是**新行**，被锚点指着的那一行**原样留下**，而且**它的锚点不变**——模型插完一段之后，原来
手里那些锚点还有效，不需要重读。这一点要在实现上真正成立（内部折算成一次「首尾都指同一行」的替换时，
必须把那一行原样写回，锚点才会按位置存活），也要有用例钉住。

**插入是字面插入，不做边界去重。** 05 的去重是为「删了又写回来」这种手抖准备的；`insert` 是明确要求
把内容加进去，模型插一行「与邻行相同」是它的意图，不是笔误。所以 `insert` **永不**走边界去重
（参考实现同样把这一条写成显式豁免）。

**空文件也能插。** 空文件 read 出来是一个内容为空的锚点行，`insert` 对着它 `after` 就是往空文件里写
第一段内容——这条路径要通。
