# spec: 卡与行不许有两种间距（step-row-gaps）

2026-09-21 立（主人报的原话：「工具调用和上下文注入 间距不一样」），当日在这个分支上落地。

**一句话**：会话栏里**相邻的两条步骤**——工具行、思考行、注入的上下文卡，不论各自落在哪条消息里——
之间只许有它们自己的 `py-1.5`（12px），不能有第二种距离。

## 现场（真浏览器量到的，脚本原样输出见 `evidence/before.txt` / `after.txt`）

| 相邻的一对 | 修前 | 修后 |
|---|---|---|
| 卡 → 卡（开场块，一块一条消息） | **24px** | 0px |
| 工具行 → 工具行（两条消息） | **8px** | 0px |
| 同一消息里的两条（思考 → 工具、行 → 卡） | 0px | 0px |
| 刷新重建之后，同上的每一对 | 24 / 8 / 8 / 8 | 0px |

**0px 不是「贴在一起」**：每行自己的 `py-1.5` 就是读到的这 12px，盒子的边是相贴的。这条规矩的正文在
`.scratch/flat-step-rows/spec.md`（本票在该文件追加了复议，因为 8px 那个数被推翻）。

三个数并存就是主人看到的那件事：卡与卡之间隔着整整一个轮次的 24px，工具行之间 8px，同一消息里 0px。

## 根因（两处：一处是漏的，一处是随手写的）

1. **负上边距只盖住了助手消息。** 消息组 `gap-y-6` 是 24px，助手消息用一条负上边距把它抵回去
   （修前 `-mt-4`，抵 16 → 剩 8px）。而**卡的消息**——会话出生时一块一张的 `session-opening-N`、
   以及重建之后一条 `CUSTOM` 一张的注入卡——一条负边距都没有，于是它保留整个 24px。
2. **抵多少是随手写的数。** `-mt-4` 抵 16px 而不是整条 24px，于是「行与行」「卡与卡」不是同一个数，
   而规矩要的正是同一个数。

## 决策

1. **`STEP_SPACING = "-mt-6"`，抵掉整条组间距**，写一次、两处用（助手消息、卡的消息）。
   于是任何一对相邻步骤的**盒子**间距都是 0，读到的那 12px 全是行自己的 padding。
2. **「前一条是不是步骤」由一个判据回答：`isStepAfter`。** 助手消息是、卡的消息是
   （`isCardOnly` / `isOpeningEntryId`），**人的消息不是**——那是真正的轮次边界，该保留消息组的
   24px。从邻居身上读，理由与 `isTurnEnd` 同（不用一个要人去同步的字段）。
3. **卡与工具行是同一个列表里的两种行。** 卡说的是「模型手里被塞了什么」，与一次 `bash` 的返回值
   是同一类事实，读的人也在同一个列表里遇到它们——所以它照步骤的间距，不照轮次的。

## 同一票顺带修的：这套量法原先量不到这件事

`walkthrough.mjs` 是上一轮留下的半成品：它**打算**量这件事，但三处让它量不到。

1. **夹具画不出一串卡。** 它绑的目录只有一份 `AGENTS.md`，技能清单那块在临时家里不存在——
   开场只有**一张**卡，「卡与卡之间多少」这一对永远测不出来。现在有 `fixture/`：三份指令文件
   （`.harness/harness.edn` 的 `:instructions {:files [...]}`，`harness.edn` 里写了为什么），
   开场就是三张卡、一块一条消息。
2. **同一消息里的那几对被过滤器丢掉了。** `steps` 原先只取 `messageSpan === 1`，于是
   「思考 → 工具」与「行 → 卡」（先画的那条路正是把卡画在同一消息里）**从来没被断言过**。
   规矩说的是「同一个数，落在哪儿都一样」，所以现在取 `<= 1`——只有跨过人的消息的那一对不算。
3. **两张截图都拍在最后**，于是逐字节相同（`gaps.png` 与 `gaps-rebuilt.png` 曾经同哈希）。
   现在一张拍在刷新前、一张拍在刷新后：同一场对话画两次，正是第二节要对照的东西。

`go.json` 也补了两段 `reasoning`——脚本头注释说它量三种行，而夹具原先只画得出两种。

## 怎么验证

```
node scripts/dev.mjs --scripted .scratch/step-row-gaps/go.json --ui-port 5311
node .scratch/step-row-gaps/walkthrough.mjs http://localhost:5311/
```

脚本自己在 `fixture/` 上开会话，所以不需要第二个参数；截图落 `evidence/`。

|---|---|---|
| 真浏览器 | 上面两条命令，修前 / 修后各一次 | 修前 **3 RED**（24 与 8 两个数并存），修后 **ALL GREEN**（六对全是 0px，三种行都在） |
