# 06 — 对话只留会话内容：步骤折起来，轨迹点开才按需流式取

**主人定的口径（2026-09-24）**：

> 后端只推送会话内容，轨迹点击按需+流式加载，其他会话都折叠，没有结论就全部折叠，
> 不要展示最后一次思考或者工具调用，始终展开的只有展示运行中的会话。

（这里「会话」指对话视图里的**一轮 / 一个步骤**——2026-09-24 当场问清的。）

**What to build:** 把这句话落成两件事——**折叠的判据**与**轨迹的取数时机**：

1. **下行只承载会话内容。** `events.mux` 的 run 帧 / `events.host` 的列表只谈「这一场谈了什么」：
   用户消息与助手的回答（步骤是 AG-UI 帧的一部分，仍走这里）。轨迹里**只有记录才有**的那些事实
   ——system 字节、注入的上下文、工具表、用量、段时间——**不占下行**，它们按需取。
   协议一个字不动（不加帧），这条是**别把轨迹塞进帧**的约束。
2. **轨迹点击按需 + 流式加载。** 打开`轨迹`、或点开某一轮/某一步，才去取它的轨迹；并且**边折边到**，
   不再一次把整份折好的 payload 取回来。
3. **只有正在跑的那一轮是展开的。** 一轮停下就折起来，它的步骤（思考、工具行）收进摘要行；
   **正在跑的那一轮始终展开**——它的思考在流、工具在跑，读者要看的就是它。
4. **没有结论就全部折叠。** 一轮停下却没有答案（最后一段助手正文）⇒ 连它最后一条也折起来，
   只留摘要行。
5. **折叠态不许露出「最后一次思考或工具调用」。** 折起来能看见的只有**答案**；最后一步是思考或
   工具调用时，它不能被留在外面冒充结论。

## 今天的样子（对着代码核过）

- **折叠**住在 `ui/src/components/turn-steps.tsx`：判据是 `useStepFold`（`"none" | "step" | "head"`）
  与 `lib/turns.ts` 的 `turnBounds` / `turnIsSettled` / `turnCounts` / `turnSummaryLabel`；
  渲染在 `components/assistant-ui/elements/thread.aui.tsx`（`fold === "step"` 整条 `hidden`，
  `fold === "head"` 折起本条内容、画出摘要行，`fold === "none"` 照画）。摘要行只印
  `N 次工具调用 · M 条消息`，所以「运行中展开、停下折叠」这半**已经在**。
- **缺的那一格**：`useStepFold` 的 `tail || !folded ? "none" : "step"` —— **tail（最后一条）永远照画**。
  于是「这一轮没有答案」时，露在外面的正是**最后一次思考 / 工具调用**：第 4、5 条要消掉的就是它。
  今天也**没有**「这一轮有没有结论」的判据（`turnCounts` 只数工具调用与消息条数）。
- **轨迹**今天由 `lib/trajectory.ts` 的 `trajectoryFor(threadId)` 一次取回整份 payload
  （`GET /api/threads/<stem>/trajectory`），取数时机是视图挂载 / 会话变化 / 一次调用结束
  （`components/trajectory-view.tsx` 的 `useEffect`）。**不是点开才取，也不是流式。**
