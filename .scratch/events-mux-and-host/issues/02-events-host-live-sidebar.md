# 02 — `events.host`：家级事实，侧栏实时

**What to build:** 第二条下行 WebSocket（`events.host`），推**家级事实**——会话出现、改名、发送时间、
跑起来、停下，项目增删，run 注册表的变化。侧栏不再只是「快照 + 刷新键」：另一个窗口一开跑，
这一页那一行自己点灯；另一个窗口归档，这一行自己消失；新会话出现不必等谁去按刷新。

**Blocked by:** 01（同一条管道与握手/订阅的形状；head 的两条 socket 用同一套连接纪律）。

**Status:** ready-for-agent

- [ ] 第二个窗口发送一个新建会话：本窗口侧栏那一行自己出现，并带「运行中」；run 结束自己摘掉。
- [ ] 归档 / 取消归档、项目增删在另一个窗口即时反映。
- [ ] 常规变化不经刷新键也能到（刷新键保留为手动兜底）；没有为列表新增任何轮询。
- [ ] 会话的 `running` 仍读服务端进程内注册表，不把快照当真相。
- [ ] 真浏览器走查：两个窗口互见彼此的发送、归档与跑停。
