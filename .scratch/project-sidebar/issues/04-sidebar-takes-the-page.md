# 04 — 侧边栏：三段位，项目与会话取代顶部横排

**What to build:** 页面变成**侧边栏 + 聊天**。侧边栏三段：顶部钉住的「新建任务」、中间**唯一滚动**的
项目区、底部钉住的「设置」。滚动区里每个项目一行——显示**末段文件夹名**（悬停给全路径）——下面挂它的
会话；当前会话高亮。assistant-ui 06 落地的那条顶部 Sessions 横排退场，不留两份。

会话行的骨架抄官方的 `@assistant-ui/thread-list`（走 `shadcn add`，与既有抄组件同一套纪律：只在必要时
就地改并标注改动）；**项目分组与三段位布局是我们自己的**，上游的按日期分组建在它自己的线程形状上。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 三段位成立：新建任务与设置不随滚动移动，项目区是唯一的滚动容器；窗口拉高拉矮都不出现整页滚动
- [ ] 侧边栏照 `flex h-dvh` 的列来写，聊天区在 `min-h-0 flex-1` 里——`Thread` 的根是 `h-full`，
      高度契约不能被侧边栏抢走
- [ ] 每个项目一行显示末段文件夹名；全路径在悬停提示里，或展开时可见（不必常驻）
- [ ] 项目下的会话按最后活动倒序；当前会话高亮且不可点
- [ ] 列表的每一行给出最后活动时间与体积（来自磁盘事实，不是库里的快照）
- [ ] 运行中切换会话 / 新建会话仍被拒，**原因显示在点下去的那一行**（06 的行为原样搬过来，不是重新发明）
- [ ] 刷新时机：切换会话后、当前会话变化后、归档后、移除项目后；另有一个手动的刷新动作，因为列表是快照
- [ ] 顶部的 Sessions 横排删除：`src` 下不留它的尸体，也不留注释掉的版本
- [ ] 抄来的 `thread-list` 元素里被本地改过的地方有标注（与既有抄组件同一套标注方式）
- [ ] 真 Chromium：三段位、滚动行为、当前会话高亮、运行中拒绝四条各看一次，截图留档

**给 05–08 的接点：** 侧边栏的四个动词（新建任务、归档、移除项目、设置）在本票里只是位子，各自的票去填。
