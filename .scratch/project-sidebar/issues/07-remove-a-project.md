# 07 — 移除项目：只解绑，不删日志

**What to build:** 项目那一行悬停出现「更多」，下拉里是「移除项目」。移除 = 项目从侧边栏消失，它的会话
不再列出来，但 `~/.clj-harness/projects/<workspace>/` 下的 jsonl **原样留着**；重新添加同一目录，会话、
归档状态、乃至它们的历史一并回来。

**这一版没有"删除"**：把不可逆的动作做成一个菜单项，省下的磁盘在今天没有意义，代价却是一次误点。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 项目行悬停出现「更多」，下拉里有「移除项目」；菜单的打开/关闭不影响行的当前态
- [ ] 移除后项目从侧边栏消失，它的会话不再列出来
- [ ] **磁盘逐字节不变**：移除前后 `projects/<workspace>/` 下所有文件的字节数与 mtime 逐字相等
      （用例直接断言，不是"看起来还在"）
- [ ] 移除**当前会话所在的项目**时，界面切到别处，不留下一个指向已移除项目的当前态
- [ ] 重新添加同一目录 → 会话回来，**归档状态与历史都还在**（历史指的是同一个 jsonl 仍能重建）
- [ ] 移除只是解绑：库里项目行的去向要说清（删行 or 标记），且这个选择不影响上面两条的验收
- [ ] 移除动作在请求进行中禁用，失败时把服务端的原因显示在那一行
- [ ] **确认文案不说假话**：它说"移除项目（会话保留在磁盘上）"这类实话，不写"删除"
- [ ] 真 Chromium：移除 → 行消失 → 磁盘对照 → 重新添加 → 会话与历史回来，截图留档
