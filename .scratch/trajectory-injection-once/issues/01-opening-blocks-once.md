# 01 — 同一段注入文本，整场只画一次

**What to build:** 轨迹里「上下文」那一列今天是把每个 run 的 submitted 侧整段铺开，于是 5 轮的会话里开场块
（`<instructions>` 与 `<skills>`）被画了 5 次，看起来像开场发生了 5 次——**那是自造，不是流程**。这一票让那一列
如实：**同一段注入文本，整场会话只画一次**，画在它第一次出现的那一轮。

开场块是这一条最显眼的例子：它是**会话开场**发生的那一次注入，不是每轮各一次。技能的正文、本 run 的 context
同一条规矩——同一段字节，只画一次。

**判据是整段文本的字节**，不是来源、也不是轮号：那是读侧唯一说得清的「同一段东西」。所以字节没变就不再画
（今天每轮都画）；字节变了就是另一段文本，会在那一轮再出现一次——`system` 条早就是这条规矩（只在第一轮出现，
变了才再出现一次），本票只是让上下文那一列与它一致。去重要记在**会话**这一层（`system` 条用的也是这一层），
不是每轮一份。
