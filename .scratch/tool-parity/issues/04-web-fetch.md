# 04 — `web_fetch`：取回一个 URL 的正文

**What to build:** 模型给一个 URL，拿回那一页的**正文**——不是 HTML 源码，是能读的文字：
`<script>` / `<style>` 的内容没了、块级标签变成了换行、`&amp;` 这类实体解开了。
拿不到的时候说的是一句指名的原因（状态码、超时毫秒数、内容类型），不是一个空页面。

从用户视角：一次调用换回一段能直接读的文字，前面告诉它这是哪个页面（最终 URL 与 `<title>`）、
有多少字节、以及是不是被截断了。

**Blocked by:** 01

**Status:** ready-for-agent

## 形状

- 工具名 `web_fetch`，参数一个：`url`（必填）。
- 答案：最终 URL（跟随重定向之后的那一个）、内容类型、字节数、`<title>`（若有）、然后是正文。
  **被截断时要标出来**（截断是信息，不是错误——与 `anchor_grep` 的做法一致）。
- `text/plain` 与 `application/json` 原样过；其余文本类型走抽取器。
- **不带 `:requires-approval`**（见 spec 决策 8：`bash` 今天就能 `curl` 且不带审批，
  给这里挂个 park 是装样子；要这道坎的会话自己装 `session-require-approval!` 或一条 hook）。
- 不适用 `:fence-paths`（URL 不是路径）。不属于任何编辑家族，两种模式都服务它。

## 决策

- **不引新依赖。** `org.httpkit.client` 已在 classpath 上（`http-kit/http-kit` 是本仓既有依赖，
  同一份 jar 里就有客户端），已核过。本仓唯一的二进制依赖是 sqlite，理由是"一次提交多个事实"必须有事务；
  HTML 解析器没有这个理由。
- **抽取器是有损的，而且写明。** 规则是小的一套：丢掉 `<script>` / `<style>` 的**内容**、
  块级标签换行、其余标签去掉、少量实体解码（`&amp;` `&lt;` `&gt;` `&quot;` `&#39;` `&nbsp;`）。
  它是**文本抽取器，不是渲染器**：JS 渲染的页面拿到的是空壳，这句话要写在工具描述里，
  不能让模型以为它拿到了整页。
- **`harness.web` 不知道任何厂商**（搜索厂商在 05 的 `harness.web.search` 里）。
  抽取器是一个**纯函数**（字符串进、字符串出），所以它不必靠 socket 才能被测。
- **编码明写 UTF-8（或有声明就用声明），永不依赖 JVM 默认字符集**——`deps.edn` 那条注释就是为这个写的。
- **不跟随重定向到别的协议**，重定向链不终止是**指名拒绝**（说清跳了几次），不是挂死。
  报告最终 URL 意味着链路要看得见，所以这不是"打开发射后不管"就完事的。
- **4xx / 5xx 是指名拒绝**（报出状态码与最终 URL），不是"取到一页空文"。
- **本机地址不做黑名单。** 门槛在 park 与围栏上，不在"哪些地址看起来危险"上；
  而且测试要打的就是本机服务（本仓所有服务都用 `{:port 0}` 让 OS 分配端口）。
  写黑名单会让这个工具在本机开发场景下先坏掉，并且它挡不住任何真正想绕过的人。

## 验收

- [ ] 新命名空间 `harness.web`：客户端（超时、重定向链、大小上限、UTF-8 解码）与
      **纯函数**抽取器；超时毫秒数与大小上限都是**具名常量**，
      上限沿用 `anchor_grep` 的 `max-bytes`（51200），并在 docstring 里指回它的出处。
- [ ] 新命名空间 `harness.web-test` 写进 `harness.test-runner/test-namespaces`，
      自带一个本机 http-kit 服务（`{:port 0}`，从 `(:local-port (meta stop))` 取端口——
      本仓不许写死端口），覆盖：
      - `text/html` 里 `<script>` / `<style>` 的内容**不在**结果里，`<title>` 在；
      - 块级标签变成换行；标签内文字保留；嵌套标签不炸；
      - 实体解码（至少 `&amp;` `&lt;` `&gt;` `&quot;` `&#39;` `&nbsp;`）；
      - `text/plain` 与 `application/json` 原样过（一个字节都不动）；
      - 非文本类型（`image/png`）是**指名拒绝**，报出那个类型；
      - 404 / 500 是**指名拒绝**，报出状态码；
      - 重定向：跟随并报告**最终** URL；一条不终止的链是指名拒绝；
      - 超时：服务睡过超时，结果是一条指名拒绝、带上毫秒数，**run 不炸**；
      - 超过上限的正文被截断**并标注**（不是错误）。
- [ ] `file:` / `data:` 之类的非 http(s) 协议是**指名拒绝**（不落到 java 的异常上）。
- [ ] 抽取器有**纯函数**用例（不经过 socket）：空串、只有标签、只有 `<script>`、超长单行、
      BOM 与 CRLF 不改语义。
- [ ] 工具描述里写明它是**有损的文本抽取**（JS 渲染的页面拿不到内容），
      以及截断会发生、上限是多少。
- [ ] `tools_test/specs-expose-every-base-tool` 两份名单各加一个 `web_fetch`（排在 `todo_write` 与
      `web_search` 之间——02 / 03 / 05 同时落地时按字母序排）。
- [ ] `clojure -M:test -m harness.test-runner` 全绿（除基线的两条环境失败）。
