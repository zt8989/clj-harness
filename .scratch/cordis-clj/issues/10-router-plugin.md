# 10 — `:http/router` 插件：路由是数据

**What to build:** 路由表作为**数据**交给插件，得到「请求 map → 响应 map」的一个函数，注册成服务。
不启服务器就能测——这就是这一票单独存在的理由：路由这一半是纯的，把纯的那一半先立起来，
票 11 剩下的才是「起一个 socket」这一件事。

**Blocked by:** 02 — 服务注册表与可逆 effect

**Status:** ready-for-agent

## 验收

- [ ] 一条 route 收到 `{:request-method :get :uri "/x"}` 答 200 与预期的 body；不知道的路径答 404
      （不是抛异常）
- [ ] 路径参数（`/a/:id`）解析出来进 handler，断言 `:id` 的值
- [ ] 路由表里 method + path 重复的在**装载时就拒绝**并点名重复的那一条（不是后来者赢，也不静默）
- [ ] 这一票的测试**一个 socket 都不开**（纯数据进、纯数据出）
- [ ] 撤销后路由服务不在表里
- [ ] 零新增依赖：路由用数据表达、自己分派——今天手里的东西够用
