# 07 — 热重载：同一个 id 用新定义换掉

**What to build:** REPL 里改完一个插件的定义，`reload-plugin!` 把它换掉：旧 fiber 的 disposer 全撤（LIFO），
新定义装上；**注册表本身不重置**（`defonce`），所以别人的插件与状态都还在。这一票是「REPL 里改一个路由
不用重启」这件事的机制那一半；看见它的那一半在票 15。

**Blocked by:** 05 — 依赖消失即撤销（级联卸载）

**Status:** ready-for-agent

## 验收

- [ ] 重载一个注册了服务的插件：旧定义注册的服务不在表里了，新定义注册的在
- [ ] 重载**不动别人**的 fiber：另一个插件的状态与它的服务照旧，且它一次 `apply` 都没再跑
- [ ] 重载前后 registry 是**同一个对象**（`identical?`），不是被重建了一份
- [ ] 新定义的 `:inject` 没满足时，重载后它停在 PENDING（与票 03 一致），旧的那一份已经撤干净
- [ ] 不叠层：连续重载 5 次，注册表里同一个 id 只有一条，服务表里没有旧值残留
- [ ] 新定义与原定义**同一个 id 但不同依赖**时，重载后依赖门按新定义算（不是按旧的）
