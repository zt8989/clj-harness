# 11 — `:http/server` 插件：第一条真路径

**What to build:** `:inject [:config :http/router]`，起一个真服务器把路由发出去；撤销时停服、把端口交回。
这一票是「数据驱动的装配」第一次跑成一件人能看见的事：一个真 HTTP 请求，答案来自票 10 那张路由表，
端口来自票 08 那份配置。

**Blocked by:** 08 — `:config` 插件；10 — `:http/router` 插件

**Status:** ready-for-agent

## 验收

- [ ] **不写死端口**：用端口 0 让 OS 分配，从绑定后的实际端口发请求（本仓明文规矩）
- [ ] 真 HTTP 请求打到路由：路由答 200，body 与票 10 里那条一致
- [ ] `:config` 或 `:http/router` 缺一个 ⇒ 停在 PENDING，而且**一个端口都没占**（断言端口没被绑过）
- [ ] 撤销：端口释放——同一个端口**立刻**能再被绑上（一条断言钉住）
- [ ] 撤销之后那个端口不再有人听（连接被拒，不是只停了一半）
- [ ] 零新增依赖：HTTP 用今天手里的那套起（走 socket 的那一半由实现按仓库纪律选）
