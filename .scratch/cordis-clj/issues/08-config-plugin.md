# 08 — `:config` 插件：配置就是一个服务

**What to build:** 一个插件把配置读成 `:config` 服务（EDN 文件 + 环境变量 + 默认档），别的插件 inject 它。
这是 Web 那一串的第一张，也是「一个最普通的插件长什么样」的样板：不启任何东西、不占端口、只注册一份数据。

**Blocked by:** 02 — 服务注册表与可逆 effect

**Status:** ready-for-agent

## 验收

- [ ] 三种来源各有一条断言：文件里有、文件里没有而环境变量有、两个都没有时落默认档
- [ ] 优先级写进实现并断言：环境变量盖过文件值
- [ ] 读不动时**不静默用默认**（文件坏、类型不对）——点名是哪一份文件的哪一个键
- [ ] 撤销后 `:config` 不在表里（与票 02 同一条判据）
- [ ] **零新增依赖**：读 EDN 与环境变量今天手里的东西就够（不引配置库）
- [ ] 测试用临时目录造配置文件，**不碰真配置家**（本仓的测试隔离规矩）
