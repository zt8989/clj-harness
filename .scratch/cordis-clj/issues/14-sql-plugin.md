# 14 — `:db/sql` 插件：连接池的生命周期

**What to build:** inject `:config`，起一个连接池、注册成服务，别的插件取它查库；撤销即关池。
这一票的重点不在 SQL 而在**生命周期**：池是一个要死的东西，而插件的 disposer 是它唯一的死法。

**Blocked by:** 08 — `:config` 插件

**Status:** ready-for-agent

## 验收

- [ ] 一条查询端到端（建 → 写 → 读）在测试里跑通，库落在临时目录里（**不碰真配置家**）
- [ ] 撤销后池真的关了：再查报得清「已关闭」，不是挂在那儿等自己超时
- [ ] 查询**参数化**，不拼字符串（有一条断言钉着占位符那条路）
- [ ] 连不上时报出配置里的目标与原因，不是裸抛一个栈
- [ ] 池参数（大小、超时）从 `:config` 来，不在代码里写死
- [ ] 零新增依赖：库里已经有那一个二进制依赖（`sqlite-jdbc`），这一票不引第二个
