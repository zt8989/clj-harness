# 12 — `:http/middleware` 插件：五样横切

**What to build:** 参数解析、会话、CSRF、静态文件、异常处理作为一组中间件挂进 route 栈，**顺序由数据说**。
它们的共同点是「每一件都不属于任何一条 route，却作用于每一条」——所以它们是插件，不是路由表里的字段。

**Blocked by:** 11 — `:http/server` 插件

**Status:** ready-for-agent

## 验收

- [ ] 缺必填参数 ⇒ 4xx，且报文说清**哪一个**参数缺（不是空白 400）
- [ ] handler 抛异常 ⇒ 5xx 加一条日志，而不是把连接掐断
- [ ] 约定目录里的静态文件发得出去（Content-Type 正确）
- [ ] 目录外的路径取不到（穿越不掉：`../` 那一类路径断言被拒）
- [ ] 中间件顺序可断言（例如会话在 CSRF 之前）——顺序写进实现并在测试里钉住
- [ ] 撤销后中间件不再生效：同一个请求回到没有中间件时的形状
- [ ] 一条真请求走通「中间件 → 路由 → 响应」整条路（不只有单元那一半）
