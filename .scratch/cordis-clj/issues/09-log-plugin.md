# 09 — `:log` 插件：日志的去处是服务

**What to build:** 日志后端作为一个插件装上（落到约定的去处），别的插件 inject 它取一个 logger。
撤销即撤净——是「撤掉」，不是「关掉一层」而底下还叠着。

**Blocked by:** 02 — 服务注册表与可逆 effect

**Status:** ready-for-agent

## 验收

- [ ] 装上后一条日志落到约定的去处（文件可读 / 可捕获，两面都断言得到）
- [ ] 撤销后不再落：再写一条，去处里没有新行
- [ ] 装→撤→再装，不出现双写（不叠层）
- [ ] 这一票是**包装**本仓已有的日志栈，不是换掉它（`deps.edn` 里现有那套）
- [ ] 日志行里的会话/上下文信息是**调用方给的**，插件不猜、不去读别人的状态
